# Overview

This document tracks the complete development roadmap of the project.

Each sprint has a clear objective, expected deliverables, and completion status.

Development follows an incremental approach to ensure stability, maintainability, and rapid progress during the hackathon.

# Development Workflow

Every sprint follows the same process.

1. Define the objective.
2. Generate code using Claude.
3. Review the implementation.
4. Test locally.
5. Commit changes.
6. Push to GitHub.
7. Update sprint status.

---

# Git Commit Convention

Use meaningful commit messages.

Examples:

```

Sprint 3: Configure Tailwind CSS

Sprint 3: Configure React Router

Sprint 4: Build Hero Section

Sprint 5: Create Dashboard Layout

Sprint 6: Implement FastAPI APIs

Sprint 7: Connect ESP32 Backend

```

# Success Criteria

The project is considered complete when:

- Landing page is fully responsive.
- Dashboard displays live sensor data.
- Backend APIs function correctly.
- ESP32 successfully sends data.
- Documentation is complete.
- GitHub repository is well organized.
- Demo is stable and presentation ready.
