# Claude Coding Rules

Before generating code:

- Read PROJECT_CONTEXT.md

- Never overwrite existing files unless asked.

- Keep components reusable.

- Use Tailwind CSS.

- Keep code production-ready.

- Keep components under 300 lines.

- Use functional React components.

- Use React Hooks.

- Use async/await.

- Never hardcode sensor values.

- Keep APIs separate.

- Comment important code.

- Make UI responsive.

- Use modern ES6 syntax.

- If a feature is large, split it into multiple files.

- Explain every generated file.
