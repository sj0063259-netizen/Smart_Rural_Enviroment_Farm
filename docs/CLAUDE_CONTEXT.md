# General Rules

Never overwrite existing files unless explicitly instructed.

Never change the folder structure.

Never generate duplicate components.

Never generate unnecessary files.

Always reuse components whenever possible.

Every generated file must follow the existing architecture.

Never hardcode sensor values.

Never generate fake sensor data.

Always keep components modular.

Prefer readability over clever code.

---

# React Rules

Use Functional Components only.

Use React Hooks.

Keep components reusable.

Separate business logic from UI.

No inline styles.

Use Tailwind CSS.

Keep each component focused on one responsibility.

---

# Backend Rules

Use FastAPI best practices.

Use async endpoints whenever possible.

Separate routes from business logic.

Keep database code isolated.

Return proper HTTP status codes.

Validate request bodies.
